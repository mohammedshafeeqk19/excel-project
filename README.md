**Project Title:
Hospital Management Data Analysis Dashboard**

Dataset Description:
This project analyzes hospital management data using Microsoft Excel.
The dataset contains information related to patients, doctors,
appointments, treatments, and hospital billing.

The purpose of this project is to transform raw hospital data into
meaningful business insights using Excel PivotTables, PivotCharts,
formulas, and an interactive dashboard.Main data areas included:

* Patient Information
* Doctor Information
* Appointment Details
* Treatment Information
* Billing Information

Tools Used:
* Microsoft Excel
* PivotTables
* PivotCharts
* Excel Formulas
* Data Analysis
* Dashboard
* Slicers / Filters
The project answers the following 5 important business questions:

1. Which doctors have the highest number of appointments?

2. What are the most common reasons for patient visits?

3. Which treatment types generate the highest billing revenue?

4. What is the monthly trend of hospital billing revenue?

5. Which doctors generate the highest billing revenue?

 KEY FINDINGS
---------------

* Sarah Taylor recorded the highest number of appointments, with
  29 appointments.

* Checkup was the most common reason for patient visits, with
  45 visits.

* Consultation was the second most common reason for patient visits,
  with 43 visits.

* Chemotherapy generated the highest treatment revenue, with
  approximately 128,855.68.

* MRI generated approximately 116,098.16 in treatment revenue.

* The total hospital billing amount was approximately 551,249.85.

* April 2023 recorded the highest monthly billing revenue, at
  approximately 64,271.54.

* December 2023 recorded the lowest monthly billing revenue, at
  approximately 27,569.71.

* Jane Smith generated the highest billing revenue among doctors,
  with approximately 95,000.59.

 PROJECT OBJECTIVE
--------------------

The main objective of this project is to analyze hospital management
data and identify useful patterns related to:

* Doctor performance
* Patient appointments
* Patient visit reasons
* Treatment revenue
* Monthly billing trends
* Doctor-wise billing revenue

The analysis helps convert raw hospital data into useful information
that can support better decision-making and business understanding.

CONCLUSION
-------------

This Excel project demonstrates how hospital management data can be
analyzed using Excel. By using PivotTables, charts, formulas, and a
dashboard, important patterns in appointments, treatments, and
billing can be identified easily.

The dashboard provides a simple and visual way to understand hospital
performance and supports data-driven decision-making.
